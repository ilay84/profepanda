# ProfePanda WebApp Improvement Plan

Homepage Interaction Cleanup
- Remove the three non-clickable landing elements ("Uso real", "Ejemplos con audio", "Práctica interactiva") so the homepage no longer presents button-like affordances that do nothing.

Logo & Brand Visibility
- Increase the ProfePanda logo size on the homepage to be roughly aligned with the main header height, improving legibility and brand recall without changing layout structure.

Branding Consistency
- Standardize the brand name spelling to "ProfePanda" wherever the logo and welcome text appear together so users see one consistent name.
- Align the welcome message typography with the logo font or a close variant at key brand touchpoints to strengthen brand recognition.

Filters & Sticky Scrolling
- Adjust the glossary filters so they scroll with the page content instead of remaining fixed, ensuring expanded dropdowns are fully reachable without scrolling through unrelated content.

Entity Naming & Context Preservation
- Align section labels across navigation and page views so the same names are used consistently ("Regional Glossaries", "Articles & Guides", "Online Exercises").
- Preserve visible entity context on individual article pages by keeping the section title present when an article is opened.
